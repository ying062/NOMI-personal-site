# V1.0 发布候选验收清单

## 前台

- [ ] 生产地址可访问且不依赖临时预览 token
- [ ] 桌面、平板、手机无横向滚动
- [ ] IP、个人介绍、图片/文章、抖音卡片、留言完整
- [ ] 图片失败、空态和网络失败可理解
- [ ] 键盘 Tab、焦点、替代文本和对比度检查通过

## 数据后台

- [ ] 管理员登录成功，退出后受保护
- [ ] 匿名访客只能写入留言和访问事件，不能读取业务数据
- [ ] PV、UV、日期趋势与测试事件一致
- [ ] 查看、筛选、标记已读、删除有效
- [ ] RLS 已开启，service role 未进入前端或 Git

## 发布与回退

- [ ] SPEC 与 TEST-REPORT 已归档
- [ ] main 已合并，远端 SHA 已核对
- [ ] 发布记录包含版本、提交 SHA、部署地址、已知问题
- [ ] 回退步骤使用 git revert 或平台上一版部署
- [ ] Supabase 生产 URL、Auth 配置和数据保留策略已记录
