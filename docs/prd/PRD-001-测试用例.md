# PRD-001 产品验收用例

状态：Ready for implementation，以下均 **Not Run**。本文件是测试设计，不是测试通过证明。
关联：[PRD](PRD-001.md)。被测提交/环境：尚无应用实现。

## 执行约定

建议测试视口 320×740、390×844 与 1440×900（测试覆盖方案，不是新增产品范围）。测试数据用虚构昵称和微信号，不使用真实访客数据；真实邮件仅在私有测试环境发送至已配置收件人。不得把接收地址或留言内容放入公开截图。失败/延迟/空态通过测试配置或受控故障注入。执行结果与证据写入对应开发轮 TEST-REPORT.md。

## 字段边界矩阵（对应 AC-004-02 / 07）

| 字段 | 有效长度 | 应拒绝输入 | 应接受边界 |
|---|---|---|---|
| 昵称 | 1–30 | 空、纯空格、31 字 | 1、30 字 |
| 微信号 | 1–50 | 空、纯空格、51 字符 | 1、50 字符 |
| 留言 | 1–2000 | 空、纯空格、2001 字 | 1、2000 字 |

逐字段测试时其他字段有效；验证错误定位、输入保留及未触发发送。字符计数口径待实现 SPEC 明确后补 Unicode/emoji 用例。另测处理中双击、服务失败、超时后重试、成功清空、真实收到完整邮件。隐私检查覆盖构建产物、页面源码、静态配置和浏览器网络响应。
