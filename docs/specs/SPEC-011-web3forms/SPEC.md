# SPEC-011：Web3Forms 留言接入

- 日期：2026-11-11
- 状态：In Progress
- 分支：feat/SPEC-011-web3forms
- 服务：Web3Forms 免费方案

## 范围

将留言表单从本地校验接入 Web3Forms；昵称、微信号、留言内容仍必填；提交中禁用按钮；成功和失败状态保留。Access Key 不写入私有邮箱或仓库文件，待用户提供后写入前端公开配置（Web3Forms 的 key 本身用于表单识别，不是邮箱密码）。

## 验收

- AC-011-01：有效表单向 Web3Forms 提交，邮件主题和字段可读。
- AC-011-02：提交中禁用，成功显示成功文案并清空，失败保留输入。
- AC-011-03：空值、纯空格和长度边界仍被前端拦截。
- AC-011-04：Access Key 未配置时页面明确提示配置缺失，不伪装发送成功。
