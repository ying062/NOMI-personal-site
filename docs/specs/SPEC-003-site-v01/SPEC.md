# SPEC-003：V0.1 整站首页实现

- 日期：2026-11-11
- 状态：In Progress
- 分支：feat/SPEC-003-site-v01
- 目标：根据参考包实现 V0.1 可运行整站：首页、作品流、抖音作品卡片、留言表单。

## 设计基线

视觉参考采用紫黑底、薰衣草紫、奶油白、荧光粉、黄色点缀、粗黑描边、贴纸/星星/手写感装饰。IP 使用 public/assets/ip-nomi.jpg。内容来自参考包中的网站内容文档；正式图片与文章仍可继续替换。

## 验收

- AC-003-01：四个模块均存在且首页顺序为介绍 → 个人作品 → 抖音作品 → 留言。
- AC-003-02：桌面和手机介绍区保持左 IP、右文字；作品图片与文章在首页连续展示。
- AC-003-03：抖音卡片使用配置主页链接，新标签打开。
- AC-003-04：留言表单校验昵称/微信号/留言长度并显示成功、失败状态；收件邮箱不进入前端。
- AC-003-05：参考包静态资源复制到 public/assets，页面可离线预览。

## 测试计划

运行静态 HTML 检查；在 390×844 与桌面视口手工检查横向溢出、图片加载、锚点、外链和表单状态。真实邮件服务尚未接入，提交使用待接入状态，不得声称已投递。
