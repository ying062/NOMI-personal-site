# 隐私与数据说明

## 收集内容

当访客主动提交留言时，网站保存昵称、微信号、留言内容和提交时间。网站记录匿名访问标识、访问路径和访问时间，用于统计 PV、UV 和日期趋势。

## 使用方式

留言仅供 NOMI 查看和回复，不公开展示，不再通过邮件自动发送。访问统计只用于了解网站使用情况和改进体验。

## 管理与删除

管理员登录后台后可以查看、标记已读和删除留言。删除后的数据不再出现在默认后台列表中；底层备份或服务商保留周期以 Supabase 配置为准。

## 第三方服务

网站使用 Supabase Auth、Database 和 REST API 保存登录及业务数据。Supabase 的服务条款、隐私政策和区域可用性适用。

## 联系

如需查询或删除留言，请通过网站留言联系 NOMI。
